# 安助：我的生活小助手

把記帳、課表、練習和 AI 助理收在同一個手機網頁 App 裡。這是「和 AI 一起寫程式：創意生活應用」課程的期中專題。

## 功能

- **記帳**：一句話記帳（例如「午餐便當 85」「刷卡 蝦皮 499」）、手動記帳、修改刪除、切換月份、每日花費圖表、類別統計、搜尋
- **現金／金融卡**：每筆帳分現金或簽帳金融卡，分開統計
- **目前餘額**：錢包現金和銀行帳戶分開計算，「領錢 1000」會從帳戶轉到錢包
- **課表**：內建課表一鍵套用、自訂節次時間、星期六、課程顏色
- **練習＋節拍器**：節拍器（30–260 BPM、點拍測速、拍號、細分）、練習計時、每日目標、一週圖表
- **問 AI**：AI 讀得到帳本、餘額、課表和練習紀錄，可以回答問題、直接幫忙記帳
- **AI 輔助**：AI 消費分析、拍照匯入帳目、上傳課表截圖自動排課
- **常用捷徑**：學校網站、證件照片一鍵打開
- **備份**：所有資料轉成一段代碼，可以搬到別的裝置

## 使用方式

1. 把這個資料夾放到任何靜態網站空間（例如 Cloudflare Pages），或直接用瀏覽器打開 `index.html`
2. 手機用瀏覽器打開網址，選「加到主畫面」就能當 App 使用
3. 要用 AI 功能時，到右上角「⚙ 設定」貼上自己的 Google Gemini API 金鑰（到 aistudio.google.com 免費申請）

## 技術

- 單一 HTML 檔，HTML＋CSS＋JavaScript，沒有使用框架
- 資料存在瀏覽器的 localStorage，不會上傳到伺服器
- 節拍器使用 Web Audio API
- AI 功能使用 Google Gemini API（function calling 用來記帳）

## 安全

- 程式碼裡**沒有任何 API 金鑰**。金鑰由使用者自己在 App 內設定，只存在自己的裝置，也不會放進備份代碼。
